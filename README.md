# Kheza Nabajo Portfolio

A personal portfolio website built with React + Vite to showcase my work as an Information Technology student, visual designer, and network designer.

This project includes:
- a modern landing page
- animated background effects and reveal transitions
- featured projects and additional project listings
- about and capability sections
- contact details and social links
- downloadable CV

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Features

- Responsive portfolio layout
- Interactive navigation
- Featured project showcase
- Custom design and animation styling
- Accessibility-focused UI elements
- Downloadable resume/CV

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/KhezaNabajo/nabajo-portfolio.git
   ```

2. Navigate to the project folder
   ```bash
   cd nabajo-portfolio
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```

5. Build for production
   ```bash
   npm run build
   ```

6. Preview the production build
   ```bash
   npm run preview
   ```

## Available Scripts

```bash
npm run dev     # run Vite dev server
```
